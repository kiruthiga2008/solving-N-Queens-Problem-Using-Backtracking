# solving-N-Queens-Problem-Using-Backtracking
An interactive Streamlit application that solves the N-Queens problem using the Backtracking technique. The system places N queens on an N×N chessboard while ensuring no two queens share the same row, column, or diagonal. It displays valid solutions, solution counts, and backtracking operations with visual board representation.
## Features

- Solves the N-Queens problem using Backtracking
- Finds all valid queen placements
- Displays the total number of solutions
- Counts the number of backtracking operations
- Shows each solution as a chessboard
- Built with Python and Streamlit

## Run

```bash
pip install -r requirements.txt

streamlit run app.py
